Overview

This project demonstrates cross-platform deployment automation for a simple containerized Python Flask application. The goal was to implement a full build-test-push-deploy loop using three distinct CI/CD tools, all pushing to a central AWS ECR registry and deploying to AWS ECS.

Key Artifacts & Configurations

1. GitHub Actions

Full CI/CD flow from push → Test → ECR Push → ECS Deploy.
